# 审计风险任务管理平台 · 前端技术白皮书

## 1. 项目定位与业务架构

本项目是一个面向审计人员的**票据风险自动化核查平台**。前端不仅承载了 UI 交互，更通过解耦的适配层架构，实现了与后端任务引擎及外部 AI 风险规则引擎的深度协同。

### 1.1 业务链路
1. **任务触发**：前端收集用户上传的“经销商订单”与“发票五要素”原始 Excel。
2. **数据流转**：前端通过 API 适配层将数据提交至 Node.js 后端，后端异步转发至算法规则引擎。
3. **状态感知**：前端基于响应式状态机进行任务轮询（Polling），实时感知算法进度。
4. **结果回显**：前端动态解析算法返回的结构化 JSON，通过虚拟 Excel 引擎进行风险明细预览与概览展示。

## 2. 核心模块技术解析

### 2.1 任务管理引擎 ([useTasks.js](file:///Users/ammaralikhan/Documents/trae_projects/Audit%20ticket/src/composables/useTasks.js))
- **设计模式**：采用单例响应式 Store 模式。利用 Vue 2.7 的 `reactive` 实现了一个轻量级的状态中心，避免了 Vuex 的繁琐。
- **轮询策略**：实现了一个智能调度器。当 `state.tasks` 中存在 `running` 状态的任务时，自动激活 `setInterval`；当所有任务均达到终态（`done` 或 `failed`）时，自动销毁定时器，节省浏览器开销。
- **关键词检索**：内置了全文模糊搜索逻辑（Search Blob），通过拼接任务的所有字段（发起人、时间、结论、文件名）实现极速的客户端过滤。

### 2.2 虚拟 Excel 预览系统 ([ResultTable.vue](file:///Users/ammaralikhan/Documents/trae_projects/Audit%20ticket/src/components/ResultTable.vue))
- **高性能网格**：放弃了传统的 Table 布局，采用 `sticky` 定位与 `flex` 结合，模拟 Excel 的视觉锚点（A-Z 列头，1-N 行号）。
- **动态渲染协议**：
    - **Schema 驱动**：表格完全由后端返回的 `columns` 定义驱动。支持 `text`（文本）、`number`（数值格式化）、`enum`（状态染色）、`date`（日期转换）。
    - **语义化染色**：内置 `toneOfValue` 逻辑，根据算法返回的风险等级（高/中/低）自动匹配 UI 规范中的颜色令牌。
- **滑动交互**：实现了容器级滚动监听，解决了在毛玻璃容器内超宽表格的滚动性能问题。

### 2.3 零感 Excel 解析适配器 ([excelParser.js](file:///Users/ammaralikhan/Documents/trae_projects/Audit%20ticket/src/utils/excelParser.js))
- **双端预览能力**：
    - **本地预览**：在文件提交服务器前，直接通过 `FileReader` 读取二进制流，利用 `xlsx` 库在内存中解析并渲染，提升用户操作容错率。
    - **远程预览**：支持从后端获取 `ArrayBuffer` 流并即时解析，无需下载文件即可查看原始数据。

## 3. 视觉设计系统 (Glassmorphism & Diffusion)

### 3.1 设计令牌 ([index.css](file:///Users/ammaralikhan/Documents/trae_projects/Audit%20ticket/src/styles/index.css))
- **弥散背景 (Diffuse Background)**：利用 CSS `radial-gradient` 在 `body` 层实现多重色块叠加，配合 `background-attachment: fixed` 确保在页面滚动时背景层次的稳定性。
- **毛玻璃令牌 (Glass Tokens)**：
    - `var(--glass-bg)`: `rgba(255, 255, 255, 0.65)`
    - `backdrop-filter: blur(20px)`
    - `border: 1px solid rgba(255, 255, 255, 0.4)`

### 3.2 UI 组件覆盖规范
- **Ant Design 重塑**：通过深度选择器（`>>>` 或 `::v-deep`）移除了 Antd 默认的实体投影，代之以基于透明度的扩散阴影（Spread Shadow），使表单与表格组件能够产生浮动在背景上的视觉错觉。

## 4. 前后端协作契约 (Contract)

### 4.1 数据交互规范
前端 API 封装在 [api/tasks.js](file:///Users/ammaralikhan/Documents/trae_projects/Audit%20ticket/src/api/tasks.js)，统一处理后端 8787 端口的代理请求。

### 4.2 算法适配层契约
前端对算法规则保持“黑盒”状态。核心交互逻辑：
- **Summary 数据**：由后端预处理好的 `tone` 字段决定前端统计卡片的颜色（danger/warning/success）。
- **Columns 数据**：决定结果表格的列顺序、标题及数据类型。

## 5. 目录结构指南

```text
src/
├── api/            # 接口层：Axios 封装与算法健康检查
├── components/     # 组件层：Excel 窗口、文件槽、统计卡片等原子组件
├── composables/    # 逻辑层：任务状态机、用户状态管理
├── pages/          # 页面层：任务管理 (Manager)、任务详情 (Detail)
├── styles/         # 样式层：设计令牌、弥散背景定义
├── utils/          # 工具类：Excel 解析逻辑、格式化函数
└── router/         # 路由配置：支持 Hash 模式与动态参数
```

1. **环境依赖**：需安装 `node` 18+。
2. **依赖安装**：执行 `npm install`。
3. **联调运行**：执行 `npm run dev`。
    - 前端控制台：`http://localhost:5173`
    - API 代理路径：`/api/*` -> `http://localhost:8787`
